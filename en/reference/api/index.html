    Python API¶

    Reference for the main public classes and functions, generated from the source docstrings. For usage, see the User Guide and Data pages.

    Entry points and configuration¶

    sopran.config.use(*, store=None, data_root=None, cache_root=None, project=None, project_root=None, artifact_root=None, download=None, frame=None, cache=None, backends=None) ¶

    Set process-local defaults for spn.kaguya, spn.view(), and Store().

    sopran.config.using(*, store=None, data_root=None, cache_root=None, project=None, project_root=None, artifact_root=None, download=None, frame=None, cache=None, backends=None) ¶

    Temporarily set process-local defaults inside a with block.

    sopran.config.save_user(*, store=None, data_root=None, cache_root=None, project=None, project_root=None, artifact_root=None, download=None, frame=None, cache=None, backends=None) ¶

    Persist user-level defaults to the SOPRAN config file.

    sopran.core.config.resolve_store_roots(root=None, cache_root=None, *, project_root=None) ¶

    Resolve the Store data root and cache root for every entry point in one order.

    Each root is taken from the argument, the session (spn.config.use), the environment (SOPRAN_DATA_ROOT / SOPRAN_CACHE_ROOT), the project [store] table, and the user [store] table, in that order. The data root falls back to <project root>/sopran_data and the cache root to <data root>/cache. project_root defaults to :func:default_project_root, so Store() and spn.kaguya resolve to the same Store.

    sopran.core.config.resolve_download_mode(value=None, *, case_value=None, project_root=None) ¶

    Resolve the download policy for every entry point in one order.

    An explicit value wins, then spn.config.use(download=...), then the environment (SOPRAN_OFFLINE forces never, else SOPRAN_DOWNLOAD_MODE), then file settings: a project case, the project [defaults], and the user [defaults]. The fallback is missing. Environment variables outrank files so that an offline compute node stays offline whatever a config says. project_root defaults to :func:default_project_root.

    sopran.core.config.default_project_root() ¶

    Root of the default project used by spn.kaguya, spn.view() and Store().

    The session project= wins, then the nearest sopran.toml above the current directory, then [project].root in the user config, then the current directory.

    sopran.core.view.view(**parameters) ¶

    sopran.core.loaders.load(dataset_id, time, *, store=None, **kwargs) ¶

    Load a dataset by stable string ID.

    The ID is the attribute path below a registered source, so load("kaguya.esa1.counts", time) equals spn.kaguya.esa1.counts.load(time). The object API remains the primary interface; this helper is for CLI, batch, and power-user dispatch.

    Store¶

    sopran.core.store.Store dataclass ¶

    Filesystem roots used by SOPRAN data discovery and products.

    dataset_records(*, layer=None) ¶

    Every dataset (manifest) in the Store, optionally of one layer.

    file_reference(path) ¶

    Portable reference to a file: Store-relative path when inside the Store, otherwise only an external hint; identity is the content checksum.

    rebuild(*, layer=None) ¶

    Rebuild every dataset catalog from shard sidecars, then the registries.

    Run after copying datasets between machines (e.g. with rsync).

    register_dataset(*, dataset_id, layer, variant_id=None, variant=None, mission, instrument, product, schema, time_coverage, source_files=(), source_datasets=(), shards=(), producer='sopran', provenance=None, status='candidate', parameters=None, context=None, storage_layout=None, dataset_version='1', partitioning=(), managed=False, _prune_shard_sidecars=True) ¶

    Write manifest, schema and catalog; shards is the complete shard list.

    managed=True marks datasets that sopran creates and reuses on its own (caches and pipeline products with content-derived variants); they are synchronized by default. Shard sidecars not in shards are removed.

    write_parquet_dataset(*, dataset_id, layer, variant_id=None, variant=None, mission, instrument, product, schema, time_coverage, frame, source_files=(), source_datasets=(), shard_path='shards/part-000.parquet', compression='zstd', overwrite=False, append=False, producer='sopran', provenance=None, parameters=None, context=None, status='candidate', dataset_version='1', partitioning=(), managed=False) ¶

    Write one shard; append keeps the other shards (catalog and sidecars).

    Appends never delete other shards' sidecars, so concurrent writers of the same dataset lose at most catalog rows, which rebuild_catalog restores.

    sopran.core.store.DatasetRecord dataclass ¶

    files() ¶

    Files of this dataset, excluding nested datasets, work/ and temporaries.

    rebuild_catalog() ¶

    Rebuild catalog.parquet from shard sidecars merged with the catalog.

    Sidecars win over catalog rows for the same path; catalog-only rows are kept and receive sidecars, so datasets written before sidecars existed are migrated. Use after copying shards from another machine or job.

    verify_shards() ¶

    Compare complete shards of catalog and sidecars with the files on disk.

    Returns lists of shard paths that are missing, have a different checksum, or are known only to the catalog or only to sidecars (rerun rebuild_catalog for the latter two, e.g. after a sync).

    sopran.core.events.EventCatalog dataclass ¶

    counts(*, freq, by=(), time=None) ¶

    Count event onsets, grouped into UTC calendar bins.

    rates(exposure, *, freq, by=('phenomenon',), time=None, exposure_column='exposure_seconds', scale=3600.0) ¶

    Join event counts to detector-specific exposure bins.

    exposure is a long table with bin_start, bin_stop, the requested grouping columns, and an exposure duration. Exposure rows are the left side of the join so bins with zero detected events are retained. Events are counted by time_start. When time is supplied it must cover complete calendar bins, because pre-aggregated exposure cannot be clipped safely to a partial bin.

    Registering data sources¶

    sopran.core.sources.register_source(name, factory) ¶

    Register factory ("module:attribute.path") as the source name.

    The factory is imported on first use and called as factory(view). It must return a source object bound to that view's time, region and context.

    sopran.core.sources.source_names() ¶

    Names of the registered sources, in registration order.

    Exceptions¶

    sopran.core.errors ¶

    BackendError ¶

    Bases: SopranError, RuntimeError

    Raised when an external or Rust backend stage fails.

    ConfigError ¶

    Bases: SopranError, ValueError

    Raised when configuration cannot be resolved or validated.

    DatasetNotFoundError ¶

    Bases: SopranError, LookupError

    Raised when a requested dataset or shard is not available.

    DecodeError ¶

    Bases: SopranError, ValueError

    Raised when mission data decoding fails.

    DownloadError ¶

    Bases: SopranError, OSError

    Raised when raw data download or local acquisition fails.

    FrameTransformError ¶

    Bases: SopranError, ValueError

    Raised when coordinate or frame transformation fails.

    PipelineError ¶

    Bases: SopranError, RuntimeError

    Raised when pipeline planning or execution fails.

    SchemaError ¶

    Bases: SopranError, ValueError

    Raised when data does not match a SOPRAN schema.
